Menu

Menu nằm ở thanh trên cùng màn hình khi cửa sổ AMS đang được chọn:

  • AMS: Cài đặt, Thư mục lưu file tải về, Mở thư mục tải về, Thoát
  • View: Tải lại trang, Quay lại, Tiến tới, Mở trang này bằng trình duyệt, Sao chép link trang
  • Help: Hướng dẫn sử dụng, phiên bản, liên hệ khi gặp lỗi

Icon AMS trên thanh menu

  • Icon nằm ở góc trên bên phải màn hình, cạnh wifi và pin.
  • Bấm chuột phải (hoặc giữ ⌃ rồi bấm): Mở AMS, Mở Chat, Cài đặt, Trợ giúp, Thoát.
  • Bấm chuột trái: mở cửa sổ AMS.

Cần biết

  • Đóng cửa sổ không tắt AMS: thông báo chat vẫn đến. Muốn tắt hẳn: ⌘ Q.
  • File tải về được lưu vào thư mục Tải về (Downloads); đổi ở AMS ▸ Thư mục lưu file tải về…
  • Mất mạng: trang mờ đi kèm cảnh báo, có mạng lại tự trở về bình thường.

Menu

Menu nằm ngay dưới thanh tiêu đề của cửa sổ AMS và cửa sổ Chat:

  • AMS: Mở AMS, Mở Chat, Cài đặt, Thư mục lưu file tải về, Mở thư mục tải về, Thoát
  • Xem: Tải lại trang, Quay lại, Tiến tới, Mở trang này bằng trình duyệt, Sao chép link trang
  • Trợ giúp: Hướng dẫn sử dụng, phiên bản, liên hệ khi gặp lỗi

Icon AMS ở khay hệ thống

  • Icon nằm ở góc dưới bên phải, cạnh đồng hồ. Không thấy thì bấm mũi tên ^.
  • Bấm chuột phải: Mở AMS, Mở Chat, Cài đặt, Trợ giúp, Thoát.
  • Bấm chuột trái: mở cửa sổ AMS.
  • Muốn icon luôn hiện: Settings ▸ Personalization ▸ Taskbar ▸ Other system tray icons ▸ bật AMS.

Cần biết

  • Bấm X không tắt AMS: thông báo chat vẫn đến. Muốn tắt hẳn: icon ở khay ▸ Thoát.
  • File tải về được lưu vào thư mục Downloads; đổi ở AMS ▸ Thư mục lưu file tải về…
  • Mất mạng: trang mờ đi kèm cảnh báo, có mạng lại tự trở về bình thường.
